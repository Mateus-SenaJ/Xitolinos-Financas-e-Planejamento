# Árvore local de execução

`cipreste` reúne notas de execução e verificação da instalação local do Xitolinos. Os serviços usam portas em loopback, mantêm dados em disco e podem iniciar sem acesso à Internet depois que as dependências foram instaladas.

Comandos e requisitos estão em [`docs/EXECUCAO_LOCAL.md`](../docs/EXECUCAO_LOCAL.md).
